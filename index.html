この画像について

わらべ館で撮った ZR の N-Log（4K 59.94p）から切り出した静止画です。RED の LUT は、N-Log を Nikon と RED の公開式で RWG / Log3G10 に変換してから当てています。Nikon 公式の N-Log→Rec.709 LUT と明るさの差は 0.001 以内でした。

「LUT なし」は Log のままの眠い画、「ZR 内蔵 REC.709」は本体の初期 LUT（IPP2 MedCon / R_2_Medium）です。ルックの差だけを見たいときは後者を基準にしてください。

LUT 一覧

ZR に同期したクラウドピクチャーコントロール 9 種と、最初から C-1 に入っている CineBias_RED です。撮影時に色が焼き込まれるので、編集なしでこの色になります。見本は Nikon Imaging Cloud の公式レシピページで確認できます。

  • 階調モード：SDR
  • H.265 10bit / 8bit
  • ProRes 422 HQ
  • R3D NE・N-RAW・N-Log・HLG では不可
画像は LUT の傾向を見るための近似です（N-Log から計算で作った Log3G10 に 33 点 LUT を三線形補間で適用、960×540 JPEG）。実機の R3D NE とは露出やノイズの出方が異なります。
